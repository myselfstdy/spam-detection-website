# 📩 Spam Detection Website

A machine learning project that detects whether an SMS message is **Spam** or **Ham (Not Spam)**.

The project includes a Jupyter Notebook for model development and a Streamlit mini website for testing messages interactively.

## 🔗 GitHub Repository

https://github.com/myselfstdy/spam-detection-website

## 📌 Project Overview

Spam messages may contain unwanted advertisements, fake offers, suspicious links, or fraudulent requests.

This project uses Machine Learning and Natural Language Processing to classify SMS messages into two categories:

- **Spam** – unwanted or suspicious messages
- **Ham** – genuine messages

The model is trained using the SMS Spam Collection dataset.

## 🛠️ Technologies Used

- Python 3.11
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
- Streamlit
- CountVectorizer
- Multinomial Naive Bayes
